# تهيئة الأسبوع 7

هذا الدرس يعمل **بلا إنترنت أثناء الحصة**. كل ما يحتاجه موجود داخل مجلد
`Week7` نفسه: الصور، والتوسيم، والنموذج الجاهز، ونتائج التدريب المرجعية.

لكن **تثبيت المكتبات يحتاج إنترنت مرة واحدة فقط**. نفّذ ما في هذه الصفحة
في البيت أو في أي مكان فيه اتصال جيد، **قبل يوم الحصة**.

---

## 1. تأكد من وجود بايثون

افتح الطرفية واكتب:

```bash
python --version
```

يجب أن تظهر نسخة **3.9 أو أحدث**. إن ظهر خطأ جرّب `python3` بدل `python`،
وإن لم تكن بايثون مثبّتة فحمّلها من [python.org](https://www.python.org/downloads/)
واحرص أثناء التثبيت على تفعيل خيار **Add Python to PATH**.

---

## 2. أنشئ بيئة افتراضية

البيئة الافتراضية مجلد معزول للمكتبات، يمنع تعارض هذا المشروع مع غيره.

من داخل مجلد `Week7`:

```bash
python -m venv .venv
```

ثم فعّلها:

| النظام | الأمر |
|---|---|
| Linux أو macOS | `source .venv/bin/activate` |
| Windows (PowerShell) | `.venv\Scripts\Activate.ps1` |
| Windows (CMD) | `.venv\Scripts\activate.bat` |

ستلاحظ ظهور `(.venv)` في بداية سطر الطرفية. هذا يعني أن البيئة مفعّلة.

---

## 3. ثبّت المكتبات

```bash
pip install -r requirements.txt
```

سيستغرق هذا عدة دقائق ويحمّل نحو **نصف غيغابايت**، معظمها مكتبة PyTorch.
نفّذه على اتصال جيد.

### إن كان لديك كرت شاشة NVIDIA

الأمر السابق يثبّت نسخة المعالج، وهي كافية لكل ما نفعله في الحصة. لكن إن
أردت تشغيل **التدريب الكامل** في القسم السادس فستحتاج نسخة GPU:

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

---

## 4. تحقق من نجاح التثبيت

```bash
python -c "import ultralytics, torch, cv2; print('كل شيء جاهز')"
```

إن طُبعت الجملة فأنت جاهز. الخلية الأولى في الدفتر تجري هذا الفحص أيضاً.

---

## 5. شغّل الدفتر

```bash
jupyter notebook week_7_training_and_finetuning.ipynb
```

أو افتح المجلد في VS Code واختر `.venv` كنواة (Kernel) للدفتر.

> **مهم:** شغّل الدفتر وأنت داخل مجلد `Week7`، لأن كل المسارات فيه نسبية
> إلى هذا المجلد. لو شغّلته من مجلد آخر فلن يجد الصور ولا النموذج.

## حلول لمشكلات شائعة

**`ModuleNotFoundError` رغم أنني ثبّتّ المكتبات**
البيئة الافتراضية غير مفعّلة، أو أن الدفتر يستخدم نواة أخرى. فعّل البيئة
ثم أعد تشغيل النواة من قائمة `Kernel → Restart`.

**`FileNotFoundError: dataset/data.yaml`**
شغّلت الدفتر من خارج مجلد `Week7`. أغلقه وشغّله من داخل المجلد.

**التدريب بطيء جداً**
هذا متوقع على المعالج. التدريب المصغّر في القسم السادس مضبوط ليكتمل خلال
أقل من دقيقة. لا تشغّل التدريب الكامل إلا إن كان لديك كرت شاشة.

**`CUDA out of memory`**
صغّر `batch` أولاً، ثم `imgsz`. راجع الجدول في القسم 5.4.

**التثبيت يفشل بسبب ضعف الاتصال**
ثبّت المكتبات واحدة واحدة بدل الملف كاملاً، وابدأ بالأثقل:
`pip install torch` ثم `pip install ultralytics`.
